# 桌面清單模式

讓 Windows 桌面除了大、中、小圖示以外，也能使用可移動的透明清單模式。

## 功能

- 清單前方顯示桌面項目的小圖示
- 逐像素透明背景與純白文字，不使用會產生粉紅邊的色鍵透明
- 透明外框只在滑鼠靠近時顯示；空白處可拖曳，四個角都能縮放且固定對角位置；圓角以接近滾動條滑塊寬度的加粗圓弧提示、直角以向內三角提示
- 每個項目的整列仍是點擊區，藍色選取底色只包住圖示與實際文字寬度
- 點擊或拖曳空白處會先取消項目選擇
- 空白處右鍵可開啟完整「樣式」設定
- 移動不會磁吸；只有在清單超出目前螢幕工作區時才阻止越界
- 寬形外框自動改成由上往下、再向右增加欄位的橫向排列
- 空白處右鍵可把其他資料夾清單釘到桌面並保存
- 只有額外資料夾清單的右鍵選單提供「關閉清單」
- 每個桌面／資料夾／自訂清單及每張便籤／代辦清單都能獨立設定純色／漸層背景、Windows 系統色、雙色各自透明度、漸層過渡／方向／單層／上下夾層／四周、字體顏色、字型、大小、粗細、行高、行距、圓角、文字對齊與左右集中／平均分散排列；檔案清單另可調整左右項目間距
- 樣式中的所有數值都使用「滑桿＋右側數字框」，Enter 只套用輸入值而不關閉視窗；字型清單會以實際字型預覽，支援中文字型優先，不支援者集中排在下方
- 字重、文字對齊與內容排列使用按鈕；字型不支援的字重按鈕會自動隱藏
- 清單與便籤右鍵可複製／貼上完整樣式，貼上後立即保存
- 樣式設定即時套用且不另放重複預覽；可反轉兩端顏色，取消會還原，「恢復完全透明」位於樣式視窗內
- 第一／第二背景顏色與透明度在子視窗調整時也會直接反映到清單或便籤，取消子視窗則立即還原
- 「Windows 系統顏色」優先使用 Explorer 工作列的實際主題色，舊版系統才退回 DWM 視窗著色
- 清單右鍵可切成置頂懸浮視窗，右上角圖釘可回到桌面
- 桌面便籤與代辦清單是兩種獨立物件；清單與物件右鍵都分別提供「新增便籤」及「新增代辦清單」，舊版混合物件會安全拆分且保留內容
- 便籤只顯示 Markdown／多段文字，不再出現代辦 `+`；本文雙擊會由原本分層視窗直接繪製編輯文字，沿用原字型、顏色、行高、行距、對齊與藍色捲動條，不產生可見的原生文字框背景或白色捲動列
- 便籤與代辦原地編輯支援滑鼠定位／拖曳選字、`Ctrl+A`／`Ctrl+C`／`Ctrl+X`／`Ctrl+V`、中英文輸入法與中文組字；編輯文字、選取底色與游標共用原生輸入框的實際換行／捲動座標，不會選到其他行；貼入網址後確認即成為可點擊超連結，貼入桌面或其他清單的檔案／資料夾則顯示物件名稱並連回原路徑
- 便籤內嵌編輯以 Enter 確認、Shift+Enter 換行，Esc 或未確認就點到其他地方會取消；拖曳超過門檻才移動便籤
- 代辦清單第一個事項前的 `+` 可新增並直接編輯；事項單擊切換完成、快速雙擊原地編輯，Enter 確認、Esc 取消；完成後加刪除線並自動移到底部
- 便籤採用與清單一致的透明背景、懸停外框、拖曳移動、縮放與即時顏色設定
- 懸浮便籤以右上角圖釘取消懸浮，內容保留安全內距，不會被圖釘或圓角遮住
- 便籤內容超過範圍時可用滾輪或懸停捲軸向下瀏覽；編輯器可拖曳分隔線調整文字／勾選事項範圍
- 從右鍵開啟的完整便籤編輯器仍由「確定」保存，Enter 不會關閉視窗
- 清單／圖示模式都能拖曳自訂排序；同一實體清單內按住 `Ctrl` 拖到空白處會建立不覆蓋原檔的「複製」項目；拖到資料夾或資料夾捷徑中央會移入，按住 `Ctrl` 則複製；拖到 ZIP／RAR／7Z 會顯示「加入壓縮檔」並由隔離程序處理，拖到資源回收筒則移至回收筒，靠近項目上下邊緣仍可調整排序
- 跨清單拖到空白處只加入參照，原清單與原始檔案位置不變；資料夾、壓縮檔與資源回收筒等實體目標優先執行實際檔案操作
- 跨磁碟移動會先完整複製再刪除來源；複製失敗時保留來源並清除未完成的目的地內容
- 排序拖曳時只顯示插入線，放開滑鼠後才正式調整順序
- 把項目拖到桌面空白處會建立新的參照清單，原始項目與檔案不會消失
- 拖出項目經過有效桌面空白區時顯示可移動游標，不會錯誤顯示禁止符號
- 從桌面主清單拖出的項目由單項清單獨占顯示；完全透明的空白區仍可右鍵及拖移，清單最小尺寸會完整容納全部項目（超過螢幕時才捲動），關閉後項目才回到主清單
- 單項／自訂清單向左右拉寬時會自動增加橫向欄位並降低最低高度；字型、字重、行高、行距或項目尺寸變更時會即時重算欄寬與最小範圍
- 固定在桌面的清單、便籤與代辦清單不會因點擊或編輯而跑到一般程式視窗前方；只有懸浮模式允許置頂
- 點清單項目只顯示項目反白並支援不受中英文輸入法影響的 `Ctrl+C`／`Ctrl+X`／`Delete`；所有桌面、資料夾及自訂清單即使完全透明，點內部空白處仍會取消項目反白、顯示選取外框並把該清單設為 `Ctrl+V` 目標，右鍵空白處或外框可開啟清單選單修改樣式；在來源清單原地貼上會自動建立「複製」、「複製 (2)」等不衝突副本，不顯示同名錯誤；點到清單外或切換應用程式會立即解除目標，完全未選取清單時不攔截快捷鍵，交由 Windows 桌面或其他程式處理
- 一般清單會自動避開其他清單；只有懸浮清單允許互相重疊
- 固定在桌面的清單與便籤彼此不重疊；新建物件只尋找空位，手動拖曳期間不動其他物件，只有放開在衝突位置後才把原位置的清單或便籤推到最近空位並保存
- 程式結束、登出或電腦關機前會再次保存所有清單與便籤；同一次執行固定使用啟動時的顯示配置 ID，避免關機期間工作區變化把資料寫進錯誤配置；單螢幕與不同多螢幕組合分開記錄內容、樣式、位置、大小及懸浮狀態；只有右鍵「關閉清單／刪除便籤」才真正移除資料
- 拖到資料夾時會顯示「移動至／複製至」提示
- 項目右鍵直接使用 Windows 原生檔案右鍵選單（包含資料夾項目）；選取後支援 `Ctrl+C`、`Ctrl+X`、`Ctrl+V` 與 `Delete`，剪貼或刪除完成會立即刷新全部相關清單
- 原生右鍵選單在獨立程序執行；Shell 外掛若在選單顯示前崩潰會自動改用安全選單，同類項目後續直接避開問題外掛；點 Windows 桌面、其他清單／便籤或其他項目會關閉原選單；安全選單會等點擊事件完成後再釋放，不會因選擇命令而觸發 JIT 例外；「內容」由另一個不載入右鍵擴充的程序顯示
- 可依名稱、類型、大小、修改日期排序，或保存自訂拖曳順序
- 桌面主清單包含可開啟的「資源回收筒」與系統圖示；資源回收筒也能單獨拖成參照清單，但不會被實體搬移或加入壓縮檔
- 每個清單可在控制框右鍵切換「清單樣式／桌面圖示樣式」並立即保存；點選這類 WinForms 右鍵命令時不會被外部點擊監看提前關閉，圖示模式仍保留移動、縮放、選取、排序與資料夾拖放操作
- 緊湊、標準、大型三種清單項目尺寸
- 安裝後可在桌面空白處右鍵開啟「桌面清單模式」子選單
- 可從桌面右鍵或工作列通知區選擇是否開機自動啟動；啟用後建立使用者「啟動」資料夾捷徑，舊版 `Run` 登錄值會自動遷移，登入啟動時會等待 Explorer 桌面就緒
- 清單右鍵可啟用自動更新或立即檢查 GitHub Releases；安裝新版前會先詢問並保留失敗時的現有版本
- 一鍵切回 Windows 圖示顯示
- 除非使用者主動拖曳或執行原生右鍵命令，工具不會改動桌面項目
- 命令列支援 `--list compact|standard|large`、`--icons`、`--startup enable|disable` 與 `--smoke-test`

## 建置

```powershell
.\build.ps1
```

輸出位於 `artifacts\DesktopListTool-win-x64.zip`。執行煙霧測試：

```powershell
dotnet run --project .\DesktopListTool.csproj -- --smoke-test
```
