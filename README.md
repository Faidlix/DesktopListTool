# 桌面清單模式

讓 Windows 桌面除了大、中、小圖示以外，也能使用可移動的透明清單模式。

## 功能

- 清單前方顯示桌面項目的小圖示
- 逐像素透明背景與純白文字，不使用會產生粉紅邊的色鍵透明
- 透明外框只在滑鼠靠近時顯示；空白處可拖曳，四個角都能縮放且固定對角位置；圓角以接近滾動條滑塊寬度的加粗圓弧提示、直角以向內三角提示
- 每個項目的整列仍是點擊區，藍色選取底色只包住圖示與實際文字寬度
- 點擊或拖曳空白處會先取消項目選擇
- 空白處右鍵可開啟完整「樣式」設定
- 移動不會磁吸；只有在清單超出目前螢幕工作區時才阻止越界
- 寬形外框自動改成由上往下、再向右增加欄位的橫向排列
- 空白處右鍵可把其他資料夾清單釘到桌面並保存
- 只有額外資料夾清單的右鍵選單提供「關閉清單」
- 每個桌面／資料夾／自訂清單與每張便籤都能獨立設定純色／漸層背景、Windows 系統色、雙色各自透明度、漸層過渡／方向／單層／上下夾層／四周、字體顏色、字型、大小、粗細、行高、行距、圓角、文字對齊與左右集中／平均分散排列
- 樣式中的所有數值都使用「滑桿＋右側數字框」，Enter 只套用輸入值而不關閉視窗；字型清單會以實際字型預覽，支援中文字型優先，不支援者集中排在下方
- 字重、文字對齊與內容排列使用按鈕；字型不支援的字重按鈕會自動隱藏
- 清單與便籤右鍵可複製／貼上完整樣式，貼上後立即保存
- 樣式設定即時套用且不另放重複預覽；可反轉兩端顏色，取消會還原，「恢復完全透明」位於樣式視窗內
- 第一／第二背景顏色與透明度在子視窗調整時也會直接反映到清單或便籤，取消子視窗則立即還原
- 「Windows 系統顏色」優先使用 Explorer 工作列的實際主題色，舊版系統才退回 DWM 視窗著色
- 清單右鍵可切成置頂懸浮視窗，右上角圖釘可回到桌面
- 可新增、編輯與刪除桌面便籤，支援 Markdown、多段文字及勾選事項；本文雙擊會在便籤原位置直接編輯，Enter 確認、Shift+Enter 換行、Esc 取消，拖曳超過門檻才移動便籤
- 便籤右鍵也能直接新增另一張便籤
- 第一個勾選事項前的 `+` 可新增並直接編輯；事項單擊切換完成、快速雙擊原地編輯，Enter 確認、Esc 取消；完成後加刪除線並自動移到底部
- 便籤採用與清單一致的透明背景、懸停外框、拖曳移動、縮放與即時顏色設定
- 懸浮便籤以右上角圖釘取消懸浮，內容保留安全內距，不會被圖釘或圓角遮住
- 便籤內容超過範圍時可用滾輪或懸停捲軸向下瀏覽；編輯器可拖曳分隔線調整文字／勾選事項範圍
- 從右鍵開啟的完整便籤編輯器仍由「確定」保存，Enter 不會關閉視窗
- 項目可拖曳自訂排序；拖到資料夾或資料夾捷徑中央會移入，按住 `Ctrl` 則複製；拖到 ZIP／RAR／7Z 會顯示「加入壓縮檔」並由隔離程序處理，靠近項目上下邊緣仍可調整排序
- 跨磁碟移動會先完整複製再刪除來源；複製失敗時保留來源並清除未完成的目的地內容
- 排序拖曳時只顯示插入線，放開滑鼠後才正式調整順序
- 把項目拖到桌面空白處會建立新的參照清單，原始項目與檔案不會消失
- 拖出項目經過有效桌面空白區時顯示可移動游標，不會錯誤顯示禁止符號
- 從桌面主清單拖出的項目由單項清單獨占顯示；完全透明的空白區仍可右鍵及拖移，清單最小尺寸會完整容納全部項目（超過螢幕時才捲動），關閉後項目才回到主清單
- 單項／自訂清單向左右拉寬時會自動增加橫向欄位並降低最低高度；字型、字重、行高、行距或項目尺寸變更時會即時重算欄寬與最小範圍
- 一般清單會自動避開其他清單；只有懸浮清單允許互相重疊
- 固定在桌面的清單與便籤彼此不重疊；新建物件只尋找空位，手動拖曳則可自由越過邊緣並暫時擠開衝突物件，離開衝突區會還原、放開後才保存擠位結果
- 程式關閉或電腦重開前會再次保存所有清單與便籤；單螢幕與不同多螢幕組合分開記錄內容、樣式、位置、大小及懸浮狀態
- 拖到資料夾時會顯示「移動至／複製至」提示
- 項目右鍵直接使用 Windows 原生檔案右鍵選單（包含資料夾項目），`Ctrl+C` 可複製選取項目
- 原生右鍵選單在獨立程序執行；Shell 外掛異常不會帶垮主清單，崩潰監看器也會自動恢復 Windows 桌面圖示
- 可依名稱、類型、大小、修改日期排序，或保存自訂拖曳順序
- 桌面主清單包含可開啟的「資源回收筒」與系統圖示
- 緊湊、標準、大型三種清單項目尺寸
- 安裝後可在桌面空白處右鍵開啟「桌面清單模式」子選單
- 可從桌面右鍵或工作列通知區選擇是否開機自動啟動
- 清單右鍵可啟用自動更新或立即檢查 GitHub Releases；安裝新版前會先詢問並保留失敗時的現有版本
- 一鍵切回 Windows 圖示顯示
- 除非使用者主動拖曳或執行原生右鍵命令，工具不會改動桌面項目
- 命令列支援 `--list compact|standard|large`、`--icons`、`--startup enable|disable` 與 `--smoke-test`

## 建置

```powershell
.\build.ps1
```

輸出位於 `artifacts\DesktopListTool-win-x64.zip`。執行煙霧測試：

```powershell
dotnet run --project .\DesktopListTool.csproj -- --smoke-test
```
